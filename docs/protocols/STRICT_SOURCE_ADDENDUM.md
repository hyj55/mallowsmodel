# Source eligibility and numerical settings addendum

Frozen before any model fit on the new data, 2026-09-25.

The 2024 dots source has both experimental arms: include A and B, all four report sizes in each arm (eight tasks). Canonical exports contain 60 participants per numbered file and 240 reports in consecutive blocks of four. Both authors' export scripts explicitly loop over one user and then that user's four responses. All 600 blocks pass the check that report sizes are exactly {2,3,5,6}. This reconstructs within-export grouping, not original named IDs or cross-export identity. The paper describes 600 participants; cross-file identity cannot be independently verified from these deidentified exports.

Use A1-A5 dated 06-08-2021, commit 8bc1331abea2fdbfb4ce75cd453565bda83f4dc7 (dots_A). Use B1/B2/B5 dated 06-08-2021 and B3/B4 dated 06-14-2021, commit e133bec2eb766cef2f0741d4e7d175f89a4719f4 (dots_B). Earlier exports are overlapping versions/pilots and are not pooled as new observations. File choice is by source version, not outcomes. Source-provided cleaning remains a provenance limitation; no additional respondent/time/accuracy filtering is applied.

Decoding is verified from data_to_json.py and rankings.js: each stored rankings vector is the user-ordered list of local item labels, where label 1 denotes the greatest true dot count, label r the smallest. Decode as sorted(groundtruth, reverse=True)[rankings-1], preserving the user's list order. Subtract 50 only as a bijective catalog label map. The values called groundtruth in the export identify the displayed images, not a response to sort or overwrite. Use actual elicited ordinal responses, never numerical ratings. All catalogs are the 30 images with 50 through 79 dots. Distinct report sizes use different image sets and are modeled separately.

Together with all eight PrefLib Dots/Puzzle files, there are 16 planned real-data tasks. The full original source files are retained locally with SHA256 manifests; scripts download original bytes and the Git repository does not redistribute the 2024 response files without a clear data license.

Numerics: Hunter's simultaneous MM starts from equal worths, normalizes only their scale, stops at maximum absolute log-worth change <1e-10 with normalized likelihood-gradient residual <1e-8, and records nonconvergence at 100,000 iterations. Root-finding tolerance for the uncapped beta profile is 1e-12. Certified integer fitting uses Conitzer et al. (2006), Linear Program 3 with integrality, solved by HiGHS with zero requested relative gap and a 120-second resource limit. Timeout without an integer optimum certificate yields no MLE result. These tolerances and resource limits are numerical criteria, not statistically different estimators. The 30-item exact sieve remains unavailable.

Both finite-state simulation generators passed independent normalization, fixed-noise, and shell-mass checks before the experimental run. Hunter's MM was checked against direct concave likelihood optimization, and the integer formulation against exact subset DP on a small case. These independent calculations are verification tools, not competing fitted estimators.
