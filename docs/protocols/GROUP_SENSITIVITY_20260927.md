# G1 execution specification

Use five fixed repetition IDs, 0–4, at each within-group training fraction 50%, 70%, 80%, plus five 70/30 whole-group holdouts; root seed 202609270. Each group contributes floor(fraction × group size) training reports. Compare pooled, local and matched-count pooled predictions on identical tests with explicit finite masks. Keep all trial/assessor groups and all candidate failures. Figures use median and observed minimum–maximum range, not population CIs. See [G1 design and results](../group_sensitivity.md) for sources, estimators and formulas.

The five-allocation reporting budget is not presented as a prospective preregistration. Allocation IDs are fixed by number, without outcome-based selection. Saved-fit producer versions and original protocol fingerprints are recorded in [technical provenance](../../results/provenance/README.md); the current summaries and validators have separate code fingerprints. Synthetic replication counts and bootstrap resampling budgets are independent of the empirical shuffle budget.
