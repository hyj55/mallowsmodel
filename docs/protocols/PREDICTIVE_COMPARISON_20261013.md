# P0/E0/B0/L0/S0 execution specification

P0 is exclusively manuscript Algorithm 4.1: likelihood-center SM versus training-validated ridge PL. E0 and B0 are supplementary estimator comparisons. P0/E0/B0 use five aligned grouped outer allocations, IDs 0–4, on every empirical task. L0 uses the same five allocations and nested development budgets. S0 uses twenty independent generated datasets per cell; these are not shuffles of a fixed dataset. See [P0](../predictive_comparison.md), [E0](../estimator_comparison.md), [L0/S0](../predictive_learning.md) and [exact computation](../sieve_computation.md) for all fitting rules, grids, sampling units and loss definitions.

The five-allocation reporting budget is not presented as a prospective preregistration. Allocation IDs are fixed by number, without outcome-based selection. Saved-fit producer versions and original protocol fingerprints are recorded in [technical provenance](../../results/provenance/README.md); the current summaries and validators have separate code fingerprints. Synthetic replication counts and bootstrap resampling budgets are independent of the empirical shuffle budget.
