## Exact sieve computation and global supplement (B0)

Remove the eight-item admission limit in the active predictive implementation. The sieve has radius phi=m*binom(m,2)/k for k retained pairs. Fixed lexicographic greedy packing uses separation greater than floor(phi). There are two exact shortcuts: phi >= binom(m,2) gives a singleton; phi < 1 gives the entire permutation space, whose empirical minimizer can be computed by exact DP with lexicographic optimum tie-breaking. No approximation or arbitrary candidate truncation is an exact sieve. For the remaining radii, enumerate lexicographically using packed orientations and construct the complete greedy packing. Representation must support more than 64 pairs. Allow 1 GiB of working arrays and 120 seconds per distinct (m,floor(phi)) packing construction; cache complete packings and explicit resource failures. Record estimated memory, radius, solver path, construction time and failure reasons. For the full-space shortcut use the same memory budget and a 120-second budget; return no Sharp fit if exact lexicographic optimality cannot be certified. These are computational resource budgets, not a restriction on W_star or item count.

Apply global pair-sieve to every empirical task with r <= R, fixing R=10 for this entire study. Choose one unordered pair uniformly per intact report, independently of its orientation, then use the same sieve. Where Sharp has no pilot reports and one global terminal block, use the same retained pairs and reuse the identical fit; publish an alias rather than counting duplicate fitting as independent evidence. Corollary 2.15's rate statement additionally requires lambda <= 1, uniform independent subsets and the stated SM law. Empirical applicability does not follow from r <= 10 alone. Record these distinctions instead of asserting an empirical minimax guarantee.
