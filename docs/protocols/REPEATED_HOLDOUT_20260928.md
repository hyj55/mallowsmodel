# P1 execution specification

Use five fixed partition streams, IDs 0–4, for each of 23 tasks, root seed 202609280. Preserve the 60/20/20 grouped training/discovery/confirmation allocation, candidate admission rules and unpenalized likelihoods. Do not reroll coverage failures or use confirmation outcomes to select an estimator. Average paired confirmation losses only across the complete planned set; retain undefined, infinite and finite-conditional cases separately. See [P1 design](../repeated_holdout.md) and [uncertainty](../uncertainty.md) for formulas and sampling units.

The five-allocation reporting budget is not presented as a prospective preregistration. Allocation IDs are fixed by number, without outcome-based selection. Saved-fit producer versions and original protocol fingerprints are recorded in [technical provenance](../../results/provenance/README.md); the current summaries and validators have separate code fingerprints. Synthetic replication counts and bootstrap resampling budgets are independent of the empirical shuffle budget.
