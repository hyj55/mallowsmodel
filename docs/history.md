# Historical experiments

The repository previously mixed several protocols. The complete pre-audit snapshot remains at [commit 89b21645d5f7eb463cc90c4e982c3a66ce805b41](https://github.com/hyj55/mallowsmodel/tree/89b21645d5f7eb463cc90c4e982c3a66ce805b41). No Git history was rewritten.

| Earlier material | Disposition |
|---|---|
| Original Beans/Sushi, capped dispersion, PL ridge, optional validation shrinkage | Replaced by a new recorded unpenalized fit on intact original data; see baseline replacement report |
| Sushi B insertion/cutting-plane heuristic results | Historical only; uncertified centers are unavailable in current comparisons |
| Exposure/ATP experiments with lambda cap, selected player catalogs and statistical stabilization | Historical only; no current scientific claim relies on them |
| PrefLib anonymous-record bootstrap intervals | Withdrawn; original descriptive fitted values remain |
| Wheat unknown-village-block intervals and village-adjusted point interval | Withdrawn; no surrogate independent sampling units |
| Original strict controlled simulations and identified-unit real fits | Retained with clarified method attribution and mathematical checks |

Some historical regularization choices are legitimate under manuscript Algorithm 4.1. Their removal from the current pipeline avoids confusing them with unpenalized estimators; it is not a claim that regularized research is invalid. The historical code and data source manifests can be reproduced by checking out the pinned snapshot in a separate directory.

Frozen protocol files are contemporaneous records. Later explicitly dated corrections supersede their affected reporting provisions, without pretending that a retrospective audit was prospectively registered. See scientific_audit.md and protocols/AUDIT_AMENDMENT.md.
