# T1_C1: NLL and report-level Kendall distance

[Definition and coverage](README.md) · [Every summary](summary.csv) · [Dispersion assumptions](../../docs/dispersion_assumptions.md)

Distances average inversions **per evaluation report**, after restricting the saved catalogue order to its displayed items. Population rows use the original probability masses, not an unweighted support average. This is distinct from error relative to a simulation true center. Lower is better. Each repetition is scored first; repetitions then receive equal weight. MCSE uses the original repetition unit (random allocation for empirical studies, independent dataset for simulations). It is not a population confidence interval. NA retains unavailable complete comparisons; the CSV separately labels available-subset means.
