# Repeated estimation of the original real-data comparisons

Thirty newly randomized 60/20/20 training/discovery/confirmation partitions for each of 23 tasks. Every model is refitted on each training partition. This corrects the original single-partition predictive estimates; it is separate from the trial/assessor sensitivity study. Read the [English report](../../docs/repeated_holdout.md), [中文报告](../../docs/repeated_holdout_zh.md) and [frozen amendment](../../docs/protocols/REPEATED_HOLDOUT_20260928.md).

## Read the loss columns correctly

`nll_mean` is the arithmetic mean of 30 separately trained models' mean whole-ranking losses. `paired_delta_mean` averages their **within-repetition paired** SM−PL differences. It is not a difference between SM and PL means taken over different available splits, and not the loss of an ensemble. Negative delta favors SM. The PL row's zero paired delta is defined only when that fit exists.

The across-all-repetitions mean is blank if any repetition is unavailable. It is positive infinity if all repetitions are defined and at least one has infinite loss. A blank is not zero and an infinite loss is not an unavailable fit. `*_defined_repeats`, `*_finite_repeats`, `*_infinite_repeats`, `successful_fits` and `status_counts` expose the denominators. `*_finite_conditional_mean` excludes entire nonfinite/unavailable repeat metrics and is explicitly conditional; it cannot replace an unavailable unconditional comparison.

Within each repeat, `finite_report_nll` and `finite_report_delta` separately restrict to finite individual reports. Their summaries are secondary and have a different denominator. `finite_report_coverage` and `paired_finite_report_coverage` give the average retained fraction. Do not confuse excluding entire unavailable repetitions with excluding zero-probability test reports inside a repetition.

`*_partition_mcse` is SD/sqrt(30), available only when all 30 scalar metrics are finite. It measures numerical precision over randomized partitions **conditional on these fixed data**. It is not a population standard error, a respondent confidence interval, or evidence that repeated test participants are independent. A separately named `*_finite_conditional_partition_mcse` uses the corresponding number of finite repetitions. No split percentile ranges or population-significance decisions are reported here.

Every score row records item/pair training coverage and the original estimator status. Finite item coverage does not certify a finite unpenalized PL MLE, the uniform display-design assumption, independent observations, or a theorem's sufficient sample-size condition. The original Sharp mechanical evaluation is retained where computationally feasible; it is not newly admitted under the more conservative policy of the separate group study.

Context/shell/pair-profile averages are descriptive and conditional on diagnostic availability. Their `recorded_repetitions` need not equal 30 for a gap/bin absent from some held-out sets. `successful_diagnostics` and each metric's finite count must be inspected. No old bootstrap interval endpoints are averaged; the empty interval columns in per-repeat context records reflect `resamples=0`.

## Reproduce and verify

```bash
python download_repeated_data.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run_repeated_real.py --workers 2
python validate_repeated_holdout.py
python validate_repeated_holdout.py --repository-only
python make_repeated_holdout_figures.py
```

Use the pinned dependencies in a separate checkout. The recorded run uses Python 3.13.7. Full source/parameter/prediction replay requires the ignored cache `results/private/repeated_holdout/` generated by the runner. It does not refit models. Repository-only verification needs no original respondent records; it verifies code/output hashes, repeat counts, failure accounting and published aggregation, not private predictions. Raw rankings, detailed fit parameters and report membership caches are not newly redistributed.

`--quick --datasets beans sushi_a sounds 00025-00000002 dots2024_A_r3 patras_cost` runs two implementation-check repetitions in a separate ignored directory. They never enter the 30-repetition publication. Full dataset batches are supported with `--datasets`; after all tasks finish, `--summarize-only` rebuilds the public tables. Cache signatures guard against resuming fits with changed core code; the full validator checks every saved signature. A different solver/platform/load can change the certificate obtained within the fixed 120-second budget. Retain that outcome rather than substituting an uncertified solution.
