# Dots 2024: two elicitation arms and four report lengths

[Data catalogue](README.md) · [Prediction](../docs/repeated_holdout.md) · [Context criteria](../docs/criteria.md#context-slope)

## Source and experimental arms

Yoo, Escobedo, Kemmer and Chiou's [Scientific Reports paper](https://www.nature.com/articles/s41598-024-52176-3) and [author repository](https://github.com/ryankemmer/simpleRatingRanking) supply the ordering task and exports. The pinned application routes show that both arms first collect an ordinal ranking. In A, numerical estimates then appear one image at a time; in B, numerical estimates are collected in a joint view using the participant's ranked order. Thus A/B label elicitation interfaces, not random train/test halves or different ranking lengths. See the source [A flow](https://github.com/ryankemmer/simpleRatingRanking/blob/8bc1331abea2fdbfb4ce75cd453565bda83f4dc7/routes/loadQuestion.js) and [B flow](https://github.com/ryankemmer/simpleRatingRanking/blob/e133bec2eb766cef2f0741d4e7d175f89a4719f4/routes/loadQuestion.js).

The experiment uses A1–A5 exports dated 06-08-2021 at commit `8bc1331abea2fdbfb4ce75cd453565bda83f4dc7`; B1/B2/B5 dated 06-08-2021 and B3/B4 dated 06-14-2021 at `e133bec2eb766cef2f0741d4e7d175f89a4719f4`. [The manifest](strict_feature_sources.json) pins ten JSON files and the export/UI decoding scripts. Overlapping source versions are not pooled.

## Released fields and decoding

| Field | Meaning | Use |
|---|---|---|
| `frames` | Number of displayed images: 2, 3, 5 or 6 | Defines a separate task and validates report length |
| `groundtruth` | Dot counts identifying the displayed images | Categorical identity decoding and external answer order |
| `rankings` | Participant-ordered list of local item labels | The only preference response fitted/scored |
| `ratings` | Numerical estimates of dot counts | Not fitted or converted to rankings |
| `rankingTime`, `ratingTime` | Response times in milliseconds | Not used for added filtering or model covariates |
| `batch` | Task-allocation batch | Metadata; not a participant ID |

The local label 1 identifies the largest actual dot count in that display, label r the smallest. The **positions in `rankings`** retain the participant's reported order. Decode by looking up each local label in the descending sort of `groundtruth`, then subtract 50 to obtain labels 0–29. Do not sort the response into the objective answer.

For example, displayed counts `[60,66,71]` and response labels `[3,1,2]` decode to `[60,71,66]`, or model labels `[10,21,16]`. The participant's placement of 60 ahead of 71 and 66 is retained. Numeric labels identify images; the model does not use dot counts as a continuous feature.

## Participant information

Each export has 240 records in 60 consecutive blocks of four. The author exporter loops over users and then their four responses; every block contains one r=2,3,5,6 report. The study reconstructs a participant-block index `(file, block)` and obtains 300 blocks per arm, matching the published total of 600 participants. Names and original worker IDs are absent from these JSONs. Cross-file identities cannot be independently verified from the deidentified files. No age, sex or geographical fields are imported into these ranking tasks.

The four tasks within an arm use the same participant split. They are not four independent populations. There is one report per participant within each arm/size task, so no within-task personal model is fitted. The study adds no response-time or accuracy exclusion beyond the source release; source-provided screening is not claimed to be absent.

## Fixed-r tasks and coverage

Different report lengths use different physical image sets. The eight tasks are kept separate, each with n=30 images corresponding to counts 50–79 and M=300 reports. Variable r across the source study therefore does not create variable-length observations within a fitted task.

Marginal source item exposure is balanced or nearly balanced, but observed pair coverage and directed wins remain uneven. Small r can prevent a unique finite unpenalized PL fit. Uniform independent subset selection is not established by these averages. P1/P2 evaluate prediction and exploratory pair, shell and context diagnostics; objective dot order supplies a reference, not a guaranteed latent preference center.
